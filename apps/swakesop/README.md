# SWOps

Local-first inventory web app for homelab devices, network equipment, Raspberry Pis, PCs, cables and related assets.

## Start

```bash
## version 1
docker compose up -d --build
```

Open:

- `http://YOUR-DOCKER-HOST:8085`

## Highlights

- Categories with icons and colours
- Parent/child connection trail
- QR codes per asset
- Photo uploads with transparent PNG support preserved
- Backup and restore
- Saved Brand and Location suggestions
- Custom fields configurable from Settings
